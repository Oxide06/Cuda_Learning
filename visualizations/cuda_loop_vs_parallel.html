CPU loop vs CUDA kernel launch

CPU way: you write the loop

for (int id = 0; id < 1536; id++) {
    whoami(id);   // one at a time
}

CUDA way: the launch is the loop

whoami<<<grid, block>>>();
// 1536 copies start; each reads its
// own blockIdx / threadIdx
